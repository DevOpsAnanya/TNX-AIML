# Week 1 — Onboarding: Sun 4 Oct 2026 to Mon 12 Oct 2026

## Week 1 goal

Week 1 gets every member to a **working setup**, a **first hands-on milestone** on their chosen
track, and a **completed worksheet**. Members starting from zero leave able to write and run a small
Python program using variables, input, conditionals, and loops. Members familiar with Python leave
with a functional OOP project, a first taste of numpy and matplotlib, and a first complete
scikit-learn fit/predict/evaluate loop.

## 9-day schedule

All days run Sun 4 Oct 2026 -> Mon 12 Oct 2026. Each day has the same three-part shape per track:
**1-3 checklist items, a hands-on deliverable, and a short review note**. The final Monday is
**review + worksheet only**, with no new topics.

| Day | Date | Track A | Track B | Track C |
|---|---|---|---|---|
| Sunday | Sun 4 Oct | Setup + first program | Setup + foundations check | Setup + orientation |
| Monday | Mon 5 Oct | Syntax, print, input, variables, types | OOP: classes, objects, methods | ML types, workflow |
| Tuesday | Tue 6 Oct | Operators, strings | Exceptions, file I/O | Data quality, leakage |
| Wednesday | Wed 7 Oct | Conditionals | Comprehensions, lambdas | Train/test split |
| Thursday | Thu 8 Oct | Loops | Iterators, generators | Regression |
| Friday | Fri 9 Oct | Lists, dictionaries | Modules, venv, pip | Classification |
| Saturday | Sat 10 Oct | Functions | NumPy basics | Metrics, bias-variance |
| Sunday | Sun 11 Oct | Small program combining fundamentals | pandas + matplotlib | First scikit-learn model |
| Monday | Mon 12 Oct | **Review, catch-up, worksheet only** | **Review, catch-up, small exercise, worksheet** | **Review, catch-up, worksheet only** |

## How to choose a track

- **Track A** is for you if you know zero or minimal coding, or just want to brush up the basics.
- **Track B** is for you if you are comfortable with variables, functions, and loops, and want to
  level up toward Python libraries.
- **Track C** is for you if you already know numpy, pandas, and matplotlib, and want to start
  machine learning.

Ask your AIML lead if you are unsure — we can help you pick, or switch once at any Monday.

## Submitting the worksheet

Your worksheet is **not** edited in the upstream repo. In your own fork:

1. Open the track's `worksheet.md` in your fork.
2. Click the pencil / Edit icon.
3. Fill in the cells (you do not need to touch the prefilled row labels).
4. Save (commit) your changes.
5. Share the link to your filled-in worksheet in your team channel.
